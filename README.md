# 🔐 SECURE — Next.js Authentication System

SECURE is a production-ready authentication and user management system built with Next.js 14 and Auth.js (NextAuth v5). It provides secure, scalable authentication for modern SaaS applications.

---

## 🚀 Features

* Email & Password authentication
* Google & GitHub OAuth login
* Email verification
* Forgot / Reset password
* Two-Factor Authentication (2FA)
* Role-Based Access Control (Admin & User)
* Protected API routes & Server Actions
* RoleGate for conditional rendering
* Login / Register components
* useCurrentUser & useRole hooks

---

## 🧱 Tech Stack

* Next.js 14
* Auth.js (NextAuth v5)
* MySQL / PostgreSQL / MongoDB

---

## ⚙️ Setup

```bash
git clone https://github.com/your-username/SECURE.git
cd SECURE
npm install
npm run dev
```

Create a `.env` file with your database and OAuth credentials.

Built for developers who want secure, flexible authentication without rebuilding it from scratch.
